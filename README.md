# Tabela de Classificação de Campeonato (Haskell)

Desenvolvido usando o compilador GHC 9.x

Vídeo: https://youtu.be/f5-vPqGU2GI

## Como compilar e executar

Na pasta *src*:

```
ghc Main.hs
ghc ../tests/Testes.hs
```

As saídas nos programas contém acentos (Paraná, Operário). É preferível o uso de um terminal em UTF-8 (`chcp 65001` no Prompt de Comando do Windows).
